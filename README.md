# AI-Based Tour Enquiry Chatbot Using Fine-Tuned LLM

## 1. Project Overview

The AI-Based Tour Enquiry Chatbot is a customer service application developed using an open-source Large Language Model (LLM). The project uses LoRA (Low-Rank Adaptation) fine-tuning to customize the model for answering customer enquiries related to tour packages.

The chatbot provides friendly, polite, and professional responses to customers asking about domestic tours, international tours, family holidays, honeymoon packages, adventure trips, and customized travel plans.

## 2. Objectives

- To develop an AI-powered tour enquiry chatbot.
- To fine-tune an open-source language model using customer service data.
- To implement Parameter-Efficient Fine-Tuning (PEFT) using LoRA.
- To generate professional and customer-friendly responses.
- To reduce manual effort in handling common tour enquiries.

## 4. Dataset Description

A sample customer enquiry dataset is created for fine-tuning the chatbot.

The dataset contains two main fields:

- **Question:** Customer enquiry.
- **Answer:** Expected professional customer service response.

Sample enquiries include:
- What tour packages do you offer?
- Can I customize my tour package?
- What is the price of a Goa tour package?
- Do you provide airport pickup?
- Do you offer honeymoon packages?
- What documents are required for international travel?

The initial implementation uses 20 sample records. A larger and more diverse verified dataset is recommended for better performance.

## 5. Model Architecture

The project uses Qwen2.5-0.5B-Instruct as its base model.

LoRA fine-tuning is applied to selected attention and feed-forward layers to train a small set of additional parameters rather than updating the entire model.

**Workflow:**

1. Load the pre-trained language model.
2. Prepare the customer enquiry dataset.
3. Tokenize the questions and answers.
4. Configure LoRA parameters.
5. Fine-tune the model.
6. Save the trained LoRA adapter.
7. Generate responses using the fine-tuned model.
8. Test the chatbot through an interactive interface.

## 6. Project Workflow

Customer Enquiry → Dataset Preparation → Tokenization → Pre-trained LLM → LoRA Fine-Tuning → Fine-Tuned Model → AI Response

## 8. How to Run the Project

1. Open the project notebook in Google Colab.
2. Enable GPU from Runtime → Change runtime type.
3. Install the required Python libraries.
4. Import the necessary packages.
5. Create or upload the tour enquiry dataset.
6. Load the Qwen2.5-0.5B-Instruct model.
7. Apply LoRA configuration.
8. Execute the model training process.
9. Save the trained LoRA adapter.
10. Run the interactive chatbot interface.
11. Enter customer enquiries and view AI-generated responses.

## 10. Advantages

- Provides quick responses to common tour enquiries.
- Maintains a friendly and professional communication tone.
- Uses LoRA to reduce the number of trainable parameters.
- Can be customized for different travel companies.
- Supports an interactive customer enquiry interface.

## 11. Limitations

- The initial dataset contains only 20 sample records.
- Response quality depends on training data.
- The model may generate inaccurate information.
- Actual package prices and booking availability require verified business data.
- More training and evaluation are needed before production deployment.

This approach demonstrates the practical application of Generative AI and Parameter-Efficient Fine-Tuning in the tourism industry.
